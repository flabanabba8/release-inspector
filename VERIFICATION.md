# Verification

- A standalone headless browser fixture with mock report data and approximate theme variables was inspected at 1280 px and 375 px. The selected report and disabled inspection button were visible without horizontal overflow; the disabled appearance was corrected and the Desktop flow test passed. This is not native Hermes Desktop or a complete accessibility review.
- Twenty-four Linux tests passed in a Hermes-compatible dependency overlay, including synthetic credentials, bounded output and timeout cleanup, CRLF line numbering, tree/history/archive scanning and omission reporting. Mixed-case private and Git-directory fixtures were refused or omitted; no real credentials were used.
- Native Windows Python 3.14 with a disposable `detect-secrets` environment passed synthetic tree, Git-history, ZIP and binary scans, mixed-case and junction omission, CRLF line/byte-offset checks, bounded output, direct-process timeout cleanup (including after stdout closes) and drive-root refusal. An initial fixture lacked a Windows profile variable; after correcting it, the run exposed a CRLF staging defect, which was fixed and retested. That run did not test the Desktop UI, Windows ACLs or descendant cleanup.
- A subsequent packaged native Windows timeout regression spawned an owned parent and child and confirmed the child was no longer active after tree cleanup; the regression is skipped on Linux. A parent that exits before cleanup, termination failures and Windows ACLs remain unverified.
- This tool cannot certify publication safety. Full personal-configuration review, all exposed refs and artifacts, screenshots, a reviewed demo and a complete publication audit remain open.
